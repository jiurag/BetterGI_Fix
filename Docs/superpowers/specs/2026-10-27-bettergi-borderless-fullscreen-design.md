# BetterGI 原神全屏窗口化设计

## 1. 目标

为 BetterGI 增加“启动时全屏窗口化”开关：

1. 由 BetterGI 启动原神时生效。
2. 游戏窗口没有标题栏和可见边框。
3. 窗口覆盖 BetterGI 主窗口所在显示器的完整物理区域。
4. 切换到其他应用后，原神不缩小、不自动最小化。
5. 不修改游戏文件，不注入 DLL，不修改游戏进程内存。
6. 不提供独占全屏功能。

## 2. 概念边界

1. 全屏窗口化使用 `-popupwindow`，本质是普通顶层窗口。
2. `-screen-width` 和 `-screen-height` 指定游戏窗口尺寸。
3. 窗口创建后使用 `SetWindowPos` 设置目标显示器的 `Left`、`Top`、`Width` 和 `Height`。
4. 不使用 `-screen-fullscreen 1` 或 `-window-mode`，避免进入游戏的全屏状态。
5. 不添加 `WS_EX_TOPMOST`，不抢焦点，不强制游戏始终置顶。

## 3. 配置与界面

1. 配置字段为 `BorderlessFullscreenEnabled`，默认关闭。
2. 首页显示单个“启动时全屏窗口化”开关，不再显示独占全屏子项。
3. 父开关关闭时，不清理、不追加任何启动参数，只保留原有首尾空白清理行为。
4. 父开关开启时，移除用户参数中的冲突项，再追加一组规范化参数。

规范化参数：

```text
-popupwindow -screen-width {Width} -screen-height {Height}
```

冲突项包括：

1. `-popupwindow`
2. `-screen-width`
3. `-screen-height`
4. `-screen-fullscreen`
5. `-window-mode`

兼容空格和等号写法，参数名不区分大小写。

## 4. 显示器与窗口定位

1. 使用 BetterGI 主窗口句柄调用 `MonitorFromWindow`。
2. 使用 `GetMonitorInfo` 读取 `rcMonitor`，不扣除任务栏。
3. 保存完整显示器坐标和尺寸，支持副屏负坐标。
4. 原神窗口出现后调用 `SetWindowPos`，使用 `SWP_NOZORDER | SWP_NOACTIVATE`。
5. 最多尝试三次，并读取实际窗口矩形确认结果。
6. 定位失败只记录警告，不让原神启动整体失败。

## 5. 数据流

1. 用户开启“启动时全屏窗口化”。
2. BetterGI 启动原神前读取开关和显示器完整矩形。
3. 参数构建器清理冲突项并追加 popup 窗口参数。
4. BetterGI 启动原神并等待游戏窗口句柄。
5. BetterGI 调用 `SetWindowPos` 将窗口铺满目标显示器。
6. 后续窗口绑定、截图器和帧率解锁流程保持不变。

## 6. 错误处理

1. BetterGI 主窗口句柄无效：不注入参数，并记录原因。
2. 找不到显示器：不注入参数，并记录原因。
3. `GetMonitorInfo` 失败：不注入参数，并记录 Win32 错误码。
4. 显示器宽高无效：不注入参数。
5. 找不到原神窗口句柄：启动流程继续，记录窗口定位失败原因。
6. `SetWindowPos` 失败：最多重试三次，仍失败时只记录警告。

## 7. 测试策略

### 7.1 单元测试

1. 开关关闭且无用户参数：结果为空。
2. 开关关闭且有用户参数：参数内容保持不变。
3. 开关开启且无用户参数：只追加 popup 和显示器尺寸。
4. 开关开启且有普通参数：保留无关参数。
5. 开关开启且有冲突参数：移除冲突项，只保留一组 popup 参数。
6. 冲突参数使用等号、不同大小写和引号写法时仍能清理。
7. 显示器宽高无效时不注入。
8. 子会话继续固定使用 `1920x1080`。
9. 引号内的连续空白不被破坏。
10. 全屏窗口化结果不包含 `-screen-fullscreen` 或 `-window-mode`。

### 7.2 黑盒验收

1. 由 BetterGI 启动原神，日志最终参数包含 `-popupwindow`。
2. 日志最终参数不包含 `-screen-fullscreen` 或 `-window-mode`。
3. 窗口外框没有标题栏和可见边框。
4. 客户区尺寸与目标显示器完整分辨率一致。
5. 使用 Alt+Tab 切换到其他应用后，原神 `IsMinimized=False`。
6. 切换回来后窗口仍覆盖目标显示器。
7. BetterGI 可以正常绑定窗口并启动截图器。

## 8. 风险

1. 游戏版本改变参数行为：以真实启动和窗口测量为准，不修改游戏文件兜底。
2. 多显示器选择不符合预期：当前规则明确为 BetterGI 主窗口所在显示器。
3. 高 DPI 换算：使用 Win32 物理矩形，并通过 `GetWindowRect` 与实际窗口对照。
4. 参数清理误删：只匹配明确列出的五类参数，并由单元测试覆盖。
5. 反作弊策略：这是启动参数与窗口定位功能，不承诺账号安全。
